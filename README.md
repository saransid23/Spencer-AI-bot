# Spencer AI

**Advanced Voice Assistant & Intelligent Problem Solver (Version: 1.0)**

Spencer is an advanced AI Voice Assistant built using Python. Its mission is not simply to answer questions, but to think, analyze, reason, optimize, and solve problems like an experienced software engineer, AI researcher, mathematician, business consultant, and technical mentor.

## Core Features
- **Voice Assistant Mode**: Natural, conversational responses keeping under 30 seconds for average answers.
- **Problem Solving Framework**: Deeply analyzes problems to compare and recommend optimal solutions.
- **Coding & Debugging Assistant**: Specializes in Python and other major languages, emphasizing algorithmic efficiency (preferring O(log n) or O(n) over O(n²)).
- **Learning & Research**: Breaks down complex topics, verifies facts, and guides users step-by-step.
- **System Design**: Guides architecture, DB schema, caching, security, and deployments.

## Architecture
- **Backend**: Python (FastAPI/Flask) - better suited for AI and ML libraries.
- **Frontend**: HTML5, CSS3, Vanilla JS (or lightweight framework) for responsiveness and animations.
- **Database**: MongoDB (motor/mongoengine) for data persistence.
- **AI & Memory**: Integrates with LangChain, LlamaIndex, OpenAI SDK, Whisper, FAISS, ChromaDB, etc.

## Setup Instructions

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the backend:**
   ```bash
   python backend/main.py
   ```

3. **Open the frontend:**
   Open `frontend/index.html` in your web browser.
