Spencer is a Python-based AI voice assistant built to do more than answer questions. It thinks, analyzes, reasons and optimizes, acting like a software engineer, AI researcher, mathematician, business consultant and technical mentor rolled into one.

<br>

## ✨ Core Features

| | Feature | What it does |
|:---:|---|---|
| 🎤 | **Voice Assistant Mode** | Natural, conversational replies, kept under 30 seconds for average answers |
| 🧠 | **Problem Solving Framework** | Analyzes problems in depth, compares options and recommends the best one |
| 💻 | **Coding & Debugging** | Python and other major languages, favoring O(log n) or O(n) over O(n²) |
| 📚 | **Learning & Research** | Breaks down complex topics, verifies facts, guides step by step |
| 🏗️ | **System Design** | Architecture, DB schema, caching, security and deployment guidance |

<br>

## 🧩 Architecture

| Layer | Technology |
|---|---|
| **Backend** | Python (FastAPI / Flask), well suited to AI and ML libraries |
| **Frontend** | HTML5, CSS3, Vanilla JS for a responsive, animated UI |
| **Database** | MongoDB (motor / mongoengine) for persistence |
| **AI & Memory** | LangChain, LlamaIndex, OpenAI SDK, Whisper, FAISS, ChromaDB |
